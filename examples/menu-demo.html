Design Tokens Used

MenuItem Tokens

  • text.size.xsmall: 14px
  • text.line.xsmall: 17px
  • text.font.tech: 'PP Neue Montreal Mono', monospace
  • color.text.primary: #362C2C (default state)
  • color.text.hover: #D4D4D4 (hover state)
  • color.text.accent: #2C54FF (selected state)

Menu Tokens

  • spacing.m: 16px (padding)
  • spacing.xl: 32px (gap between items)
  • radius.s: 16px (border radius)
  • color.background.surface: #F5F5F5 (scrolling variant background)
