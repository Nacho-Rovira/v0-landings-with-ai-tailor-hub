MenuSidebar Component

Vertical sidebar navigation menu component

MenuSidebarItem States

Default, Hover, Active, and Disabled States
DEFAULT HOVER ACTIVE DISABLED
States:
• Default: Primary text color (#362C2C)
• Hover: Accent color (#2C54FF) on hover
• Active: Accent color (#2C54FF) with font-weight 500
• Disabled: Hover text color (#D4D4D4), cursor not-allowed

Proposal Navigation with Numbering

Proposal Sections with Numbered Labels
01. THE CHALLENGE 02. THE SOLUTION 03. THE APPROACH 04. RESULTS 05. TIMELINE 06. TEAM

React Usage

Component Implementation

TypeScript/React:

Design Tokens Used

MenuSidebar Tokens

  • spacing.l: 24px (gap between items)
  • text.size.small: 16px (font size)
  • text.line.small: 22px (line height)
  • font.tech: 'PP Neue Montreal Mono', monospace (font family)
  • color.text.primary: #362C2C (default text color)
  • color.text.accent: #2C54FF (active/hover text color)
  • color.text.hover: #D4D4D4 (disabled text color)

Accessibility Features

Accessibility:
• Supports keyboard navigation
• Proper ARIA attributes for disabled state
• Respects prefers-reduced-motion for reduced animation
• Semantic HTML with <aside> element for sidebar content
